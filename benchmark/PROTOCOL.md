# A3 演讲/对话手势评测协议 v0.1

所有被评对象先转换到同一个表示：A3 的 17 个手势关节角（腰 3 + 双臂 14），30 Hz；
关键点由 A3 正运动学得到。这样数据集、生成模型、机器人现有动作库放在同一把尺子下。

## 三类任务

| 任务 | 输入 | 问题 | 主要指标 |
|---|---|---|---|
| A 数据集 → A3 适配 | 公开数据集的一段（BVH / SMPL-X / 关键点）| 这批数据能不能变成 A3 可用的动作库 | 重定向保真、可执行性、静止/抖动占比、名实核对、关节与风格覆盖 |
| B 语音 → 手势生成 | 语音 + 文本 → A3 关节角序列 | 生成的动作像不像真数据、踩不踩节拍、表达对不对、机器人做不做得到 | FKD、L1Div、BC、BAS、语义规格通过率、可执行性、人工 MOS |
| C 在线编排 | 语义序列 + 预计时长 + 实测状态 | 预算内完成了多少语义、衔接代价多大、打断是否停得住 | 前缀完成率、预算利用率、桥接时长、取消延迟（来自 trace.json）|

## 指标定义

| 指标 | 定义 | 方向 | 备注 |
|---|---|---|---|
| 重定向保真 | 上臂、前臂、手三个方向在 A3 上的角误差（°） | 低 | 高误差 = 该数据集的姿态超出 A3 的运动学范围 |
| 可执行性 | A/B/C/D 等级分布；力矩超限、自碰撞、静止、抖动占比 | — | 固定根逆动力学 + A3 力矩上限 + SONIC 伺服增益 PD 跟踪 |
| FKD | 对手工运动学特征（关节角均值/方差、速度均值/方差、手部统计，74 维）拟合高斯后的 Fréchet 距离 | 低 | 与 FGD 同构；可替换为学习到的嵌入 |
| L1Div | 双手相对肩部轨迹（时间归一化）到集合均值的平均 L1 距离 | 高 | EMAGE 的 L1div |
| BC | 音频起始点到最近动作节拍（关节速度局部极小）的高斯核均值，σ = 0.3 s | 高 | 与 BEAT/EMAGE 口径一致；同时报告随机基线 |
| BAS（二值 / 高斯） | 语音重音 ±0.2 s 窗内是否有手部速度峰（apex）；最近 apex 距离的高斯核均值 | 高 | TRABot §IV-A；无重音检测时用起始强度前 30 % 的起始点代替 |
| 语义规格通过率 | 17 个语义函数各自的姿态/接触/时序规格（trabot_a3/semantics.py） | 高 | 自身标签通过率 + 全库“已验证参考”数 |
| 关节覆盖 | 17 个关节各自使用范围 ÷ 限位范围 | 高 | 低覆盖 = 库里缺这种姿态 |
| 风格覆盖 | 能量 × 节奏 4×4 格的占用数 | 高 | — |
| 人工 MOS | 自然度、连贯性、语义匹配、风格符合度，1–5 分 | 高 | 用评审台采集，每片段 ≥ 3 人 |

## 判定建议（第一版，待校准）

- 数据集进入候选：重定向平均误差 < 5°、静止占比 < 30 %、力矩超限 < 5 %、至少覆盖 8/17 语义。
- 生成模型可用：FKD 不高于“同分布两半”基线的 3 倍；BC 与 BAS 明显高于随机基线；语义规格通过率 ≥ 真数据；可执行性 A/B ≥ 80 %。
- 编排可上线：预算内前缀完成率 ≥ 90 %；取消后 1 个 atom 内停下。

## 已知局限

- FKD 用手工特征，不如学习嵌入敏感；BC 在动作节拍密集时接近饱和，看随机基线差距而不是绝对值。
- 语义规格阈值是第一版，需要用评审台里的“规格判定是否准确”校准。
- SMPL-X 与 2D 关键点数据集还需要各自的适配器（当前只有 BVH）。
