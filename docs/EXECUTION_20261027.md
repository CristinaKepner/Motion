## 3. 新库与同口径比较

流程：原始重定向 → 局部关节限位投影 → 平滑 / 放慢 / 必要时开臂与缩幅 → 对照原始方向复核 → 切分 atom → 再复核方向、静止与力矩。

原有“一关节靠近限位就把全臂缩幅”的修复会破坏手到胸口的接触关系。本轮先把超限关节单独投影到 0.051 rad 裕量，保留其他关节，所有变更记入 `admission.json`。选出 **298 个修复窗口**，切出 572 个候选，最终保留 **325 atom**；最终每个 atom 的平均方向误差均 <5°（最大 **4.974°**，均值 **3.058°**）、非静止、最大力矩比 ≤1。力矩门槛比“超限帧 <5%”更严格。

| 指标 | 旧 133 atom | GENEA 325 atom |
|---|---:|---:|
| A/B 个数 | 70 | 233 |
| A/B 比例 | 52.6% | 71.7% |
| 静止片段比例 | 45.9% | 0% |
| 有规则匹配的语义 | 13/17 | 16/17 |
| 自碰撞片段比例 | 2.3% | 30.2% |
| 抖动片段比例 | 33.8% | 29.5% |

三个核心目标（atom 数、A/B 比例、语义覆盖）均提高。**新库仍有 98 个自碰撞片段，不能整体视为可执行库**；C/D 留作评审与诊断，demo 只选 A 级且无碰撞/静止/力矩/跳变标记的片段。等级分布 A=215、B=18、C=10、D=82。

修正规则把分离时段的姿态与摆动拼成同一事件的问题：否定要求同一胸肩高度、身前区间内侧向摆动，问候要求举过肩期间真正左右摆动。收紧后新库**问候 0、否定 2**；指自己 5、感谢 1。完整库 16/17，A/B atom 覆盖 15/17。**120 个 atom 无规则匹配，标为 unverified**。方向描绘通过率 **36.9%**，仍标记过宽警告，需要人工审核，不能靠降低阈值消除空格。

36 个基底生成 **204 个变体**，其中 **201 A/B（98.5%）**；新评审包合计 **529 片段**。同一新版规则、七种共有风格、所有等级下，语义×风格矩阵占用 **82→97 /119**，空格 **37→22（减少40.5%）**；见 `semantic_style_comparison.json`。能量×节奏 4×4 格并未明显扩大：新 atom 10 格，加变体 11 格；不混同两种覆盖指标。

所有语义均为运动学规则反查，**无人工语义真值**。来源许可证与改动说明保留在 `results/genea/ATTRIBUTION.md`、`LICENSE.txt` 和 `SOURCE_README.txt`，派生数据沿用 CC BY-NC 4.0。

## 5. 语音端到端验收件

- [`demo.mp4`](../results/genea_demo/demo.mp4)：**21.00 秒，1280×480，25 fps，H.264 + AAC**，全身与手部双视角，中文字幕和到达/落拍/迟到叠字。
- 文本：“第一，展开讨论，一起看看这个方案。第二，分成步骤，一件一件把事情做好。第三，这很重要，我们要认真检查结果。”
- edge-tts Xiaoxiao、原生 WordBoundary 时间戳；“展开”→turn_open、“步骤”→enumerate、“重要”→emphasize，实际调用 Planner 选三个 GENEA atom。手部“第一/第二/第三”→O10 1/2/3。
- 实际腕部速度峰相对关键词：**+0.0333、−0.0071、−0.0003 秒**，无 >0.2 秒迟到事件。根高最低 1.063 m，最大倾角 2.80°、根漂移 0.0426 m，无失稳。
- 三个手部目标最大误差分别约 **0.00250 / 0.00184 / 0.00198 rad**；1→2 期间本应保持伸展的关节最大偏差 **0.000243 rad**，无回握拳插入。
- `trace.json`、`report.json`、`reference_30hz.csv`、`speech.wav`、分句 WordBoundary 与 `rollout.npz` 可逐项复核。21.033 秒是输入参考的帧数/fps 时长；官方插值后的实际视频 21.00 秒，两者分字段记录。
- 这是**预先合成语音的定时编排**，不是在线未知语音到达延迟的验收，也不是动作自然度/语义人工 MOS 验收。三个片段满足规则，是否自然还需观看评审。
